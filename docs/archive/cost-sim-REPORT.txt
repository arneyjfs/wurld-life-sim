   COST-VOL-1: infra is rescaled WITH volume here, not held flat. Most of it
   is message-driven — Cloud Run bills per invocation-second and the fan-out
   makes one message ~7 invocations. Holding it flat overstates a low-volume
   user by roughly 2x, which is the wrong direction for a pricing decision.

   Cloud Run is the larger half of infra, not Firestore — which is why
   merging the translate fan-out helps infra more than it helps tokens.

   column — e.g. 250 msgs/mo lands near $0.7400 all-in rather than $1.24.
